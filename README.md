# Probably Mod Manager 0.2.3

Мод для Probably Stolen `VERSION 100-Rev6` / API `0.46D`, Steam Build `26337366`.

## Скачать и установить

Готовые файлы находятся в папке [dist](https://github.com/GafarovMaxim/Probably-Stolen-Mod-Manager/tree/main/dist) репозитория. GitHub Release пока не создан.

- **ProbablyModManager-0.2.3.zip** — полный комплект: основной мод, помощник и исходники. Содержимое `Mods/ProbablyModManager` скопируйте в одноимённую папку внутри `Mods` игры.
- **ProbablyModManager-Companion-0.2.3.zip** — только необязательный помощник с инструкцией и установщиком SteamCMD; для тех, у кого основной мод уже установлен, например через Workshop. EXE размещается рядом с `Probably Stolen.exe`.
- SHA256 архивов указан в `dist/SHA256SUMS.txt`. Основной менеджер работает при обычном запуске игры; помощник требуется для кнопки рестарта и публикации.

Для обновления уже установленного мода сначала сохраните копию его папки и замените DLL, manifest.xml и README. Не устанавливайте одновременно локальную и Workshop-копию с одним ID.

## Сборка из исходников

Нужен .NET SDK 10 и установленная игра. Из корня репозитория:

```powershell
dotnet build ProbablyModManager.csproj -c Release -p:GameDir="G:\SteamLibrary\steamapps\common\Probably Stolen"
dotnet publish Launcher/Launcher.csproj -c Release -o helper-build
```

В первой команде укажите свою папку игры. DLL появится в `bin/Release/netstandard2.1`, помощник — в `helper-build`. Библиотеки игры используются только для сборки и в репозитории не распространяются. Для запуска помощника нужен .NET 10 Desktop Runtime x64; основной мод работает в среде игры.

## Обновление 0.2.0: публикация локальных модов

Вкладка **Публикация / Publish** и кнопка **Опубликовать в Steam…** в карточке локального мода открывают форму. В ней можно задать название, описание, PNG/JPG-превью, видимость, метки, заметку об обновлении и ID существующей страницы. Пустой ID означает создание новой страницы. По умолчанию выбран личный доступ.

Публикация выполняется внешним помощником через официальный SteamCMD. Внутриигровая DLL не вызывает запрещённые SteamUGC.CreateItem/SubmitItemUpdate и не меняет штатную защиту игры. Дополнительных разрешений DLL не запрашивает.

### Подготовка и отправка

1. Запусти обновлённый `Probably Mod Manager.exe` рядом с игрой. Открой менеджер из главного меню и перейди в **Publish**.
2. Выбери локальный мод, заполни поля и укажи превью. Для новой страницы оставь ID пустым; для обновления введи существующий цифровой Workshop ID.
3. Нажми **Проверить и подготовить**. Эта операция только создаёт локальный снимок, не отправляет запросы создания/обновления в Steam и не требует входа.
4. Открой **Просмотреть отправку**: проверь видимость, превью и список файлов с размерами и SHA256. После изменения формы снимок нужно подготовить снова.
5. Для отправки укажи имя аккаунта SteamCMD, снова подготовь пакет и подтверди отправку. Пароль и Steam Guard вводятся только в отдельном окне SteamCMD. Менеджер не принимает и не хранит пароль.

Если SteamCMD отсутствует, запусти из комплекта `Install-SteamCMD.ps1 -GameDirectory "папка игры"`. Скрипт загружает официальный инструмент Valve в `Modding\ProbablyModManager\Tools\SteamCMD`; автозапуска Windows и изменений системных настроек не создаёт. Требуется интернет. В текущей локальной установке SteamCMD установлен при разработке.

### Какие файлы отправляются

Снимок содержит manifest.xml в корне, объявленные в нём DLL, README/лицензии/NOTICE и разрешённые ресурсы из Sprites, Textures, Sounds, Localization, Paper, Assets и AssetBundles. Исходники, логи, профили, сохранения, ModData, .git, служебные данные загрузчиков и библиотеки игры не включаются. Папки/файлы-ссылки и выход за пределы выбранного мода отклоняются. Максимум — 512 МБ; превью PNG/JPG — до 1 МБ и 8192×8192. Состав снимка показан перед отправкой; если мод требует ресурсов в нестандартных корневых папках, их нужно отдельно учесть до релиза — автоматический снимок их не включает.

Снимок, превью и VDF перепроверяются перед запуском SteamCMD. Живые файлы мода не загружаются вместо просмотренного снимка. Журналы и данные IPC не публикуются.

### Результат и ограничения

SteamCMD проверен анонимно: приложение 4348910 определяется как Probably Stolen, Workshop доступен в метаданных, команда workshop_build_item существует. Фактическая загрузка от авторизованного аккаунта при разработке не выполнялась: право на создание/обновление и соглашение Workshop проверит Steam при первой реальной отправке.

Процент прогресса не выдумывается: интерфейс показывает фазы и ожидание SteamCMD. Успех показывается только при подтверждении нового результата в журнале SteamCMD для конкретного item ID. При неопределённом результате требуется проверить Workshop и журнал; повторно создавать страницу автоматически менеджер не будет. Незавершённая попытка новой публикации сохраняется в `publishing/attempts`: перед её повтором нужно разрешить ситуацию вручную, чтобы не создать дубликат. Для дальнейших обновлений укажи полученный Workshop ID.

SteamCMD не умеет отменять уже начавшуюся отправку. Во время работы публикации кнопка рестарта заблокирована. При отсутствии помощника или входа отправка недоступна; подготовка пакета остаётся локальной. Метаданные отправляются одним текстом; отдельные переводы названия/описания этой версией не загружаются.

Публикуя сам менеджер в Workshop, включай только содержимое `Mods\ProbablyModManager`. Помощник и SteamCMD устанавливаются отдельно вне папки Mods; основные функции менеджера работают без помощника, публикация и кнопка рестарта требуют его.

### Помощник ручного рестарта

Запускай игру через `Probably Mod Manager.exe` рядом с `Probably Stolen.exe`. Если игра уже открыта, этот файл только подключает помощника. Можно запускать саму игру через Steam, затем отдельно открыть помощник. Он работает скрыто до обычного закрытия игры. Для следующего запуска через Steam помощник также нужно открыть отдельно; автозапуск в Windows не создаётся.

При нажатии «Перезапустить сейчас» мод отправляет свежий запрос с ID сессии и одноразовым идентификатором. Игра закрывается только после подтверждения помощника. Помощник ждёт завершения конкретного процесса, не завершает его принудительно, затем один раз запускает приложение Steam 4348910 и остаётся подключённым к новому процессу. Без запроса или при отмене запуск не выполняется. Если помощник не подключён/не отвечает, игра остаётся открытой.

Помощник требует установленный .NET Desktop Runtime 10 x64, как и прежний необязательный ярлык. Сам мод дополнительных возможностей запуска процессов не запрашивает: штатный сканер игры запрещает такой запуск внутри модов.

## Возможности 0.1.2

- Оставлены три раздела: **Моды**, **Профили**, **Журнал**. История изменений состава сохраняется внутри отчётов; отдельные вкладки «Изменения» и «Настройки» убраны.
- Полосы прокрутки: тёмная дорожка с контуром, бирюзовый ползунок с насечками, подсветка при наведении и нажатии, минимальный размер для захвата мышью. Дорожка остаётся на месте и не меняет ширину карточки.
- Превью мода сразу после заголовка карточки. Используются штатные загрузчик и кеш игры: Steam Workshop с локальным резервным изображением. Без доступного изображения выводится соответствующая подпись.
- **Ctrl+клик** добавляет/снимает выделение; **Shift+клик** выделяет диапазон в колонке; **Ctrl+A** выбирает видимые моды, если фокус не в текстовом поле. Двойной клик и перетаскивание работают с выделенной группой. При перемещении группы сохраняется её исходный порядок.
- **ПКМ по моду**: включить/выключить группу, добавить метку «На проверке», выбрать всё видимое, снять выделение, открыть чейнджлог, скопировать ID. Менеджер защищён от отключения из собственного интерфейса.
- **ПКМ по профилю**: активировать, дублировать, экспортировать JSON, удалить. Кнопка удаления также находится наверху карточки. Удаление профиля не меняет активные моды; удалённый последний профиль не восстанавливается при следующем запуске.
- **История обновлений · Steam** открывает отдельное окно с заметками автора, переключением страниц, обновлением и ссылкой на Workshop. Загрузка происходит по запросу; кеш действует до закрытия игры. Недоступность Steam или изменение разметки страницы показываются явно. У локального мода без Workshop ID кнопка недоступна.

## Журнал

Слева: время, уровень, число повторений, сообщение; поиск, фильтры, страницы, текущая/предыдущая сессия, пауза обновления списка, экспорт ZIP.

Справа: исходное сообщение движка, объяснение типа сбоя, связанный мод и основания, рекомендации, полный выделяемый стек, первое и последнее время, число повторений. Доступны копирование отдельной ошибки с диагностикой и полный отчёт с окружением.

Новые события обновляют список и счётчик, а не пересоздают карточку выбранной ошибки. Это устраняет прежнюю причину мерцания полосы прокрутки описания и сброса выделения текста.

Принадлежность кода определяется по типам из реально загруженных DLL модов. Первый кадр может показать мод, в коде которого проявилось исключение. Остальные кадры и текстовые упоминания показаны отдельно. Место проявления ошибки не доказывает первопричину: если её нельзя установить, журнал сообщает об этом. Прежние записи без стека или недоступные типы могут остаться без установленного мода.

Сообщения Unity объединяются по уровню, тексту и стеку, но исходные события пишутся в JSONL. Очередь и журнал ограничены по размеру; переполнение отмечается. Экспорт включает журнал, окружение, историю состава и ранние сообщения Player.log, если удалось их прочесть. Домашний путь, Steam ID и распространённые поля секретов скрываются в экспортируемом тексте; перед публикацией проверь архив.

## Запуск и разрешения

1. Запусти игру обычным способом через Steam. **F6** открывает менеджер, **Ctrl+F6** — штатное меню.
2. При обновлении DLL или разрешений игра может потребовать повторную активацию/проверку Probably Mod Manager в штатном меню.
3. Разрешения: `files` — локальные профили и логи; `reflection-external` — штатная автосортировка, превью, сведения о типах и необязательная интеграция MCM; `network` — чтение публичных заметок Steam. Журналы автоматически не отправляются.

**Автоматического перезапуска нет.** Список сохраняется сразу. Можно закрыть/запустить игру вручную либо нажать кнопку рестарта. Единственный вызов выхода из игры защищён явным подтверждением и ответом помощника. Процессы запускает только внешний помощник по этому запросу.

Перед активацией новых модов сохраняются штатные проверки и запросы разрешений. Отказы игры не обходятся. Изменение набора из загруженного сохранения запрещено.

## Остальные возможности

Два списка/общий список, поиск по имени/ID/автору/меткам, несколько пользовательских меток, заметки, профили состава/версий/порядка с импортом/экспортом. Штатная автосортировка; проверки отсутствующих зависимостей, циклов, дубликатов и порядка; подтверждение выключения зависимых модов. Переход в Probably MCM либо штатные настройки выбранного мода.

Манифест этой сборки игры не содержит диапазонов версий зависимостей. Менеджер не выдумывает требования к версиям и неизвестные несовместимости. Профили не включают файлы модов или настройки сторонних модов.

## Файлы

Установленный мод: `Mods\ProbablyModManager`. Исходники: `Modding\ProbablyModManager`. Данные: `%USERPROFILE%\AppData\LocalLow\Questing Goose Studio\Probably Stolen\ModData\probably_mod_manager`; профили/метки — `manager.json`, логи — `sessions`, отчёты — `exports`. Сохранения игры не изменяются.

Для удаления закрой игру и удали только папку мода. Данные и исходники можно сохранить. `Probably Mod Manager.exe` версии 0.1.3 — помощник ручного рестарта и ярлык запуска Steam. Для остальных функций мода он не нужен. Данные протокола: restart-session.json, restart-helper.json и restart-request.json; при сбое помощника — restart-helper-error.txt.

```powershell
dotnet build ProbablyModManager.csproj -c Release -p:GameDir="G:\SteamLibrary\steamapps\common\Probably Stolen"
dotnet run --project Checks\Checks.csproj -c Release -- "папка готового мода"
```
